# Jev 去 AI 味起草与独立排序

## 目标

把关系判断转成一句符合用户本人语气、能直接发送的消息。流程借鉴 Jev Chat Jarvis 的短句、多策略候选和独立排序，并作一项关键增强：诊断结果必须真正进入起草，而不是仅在起草后排序。

设计来源：[jev-chat/jev-chat-jarvis](https://github.com/jev-chat/jev-chat-jarvis)（MIT）。具体借鉴其 `ReplyClient.kt` 的短候选与策略差异、`JevQuestions.kt` 的意图／需要／动作判断和候选排序，以及知识库与历史上下文机制。没有复制其 Android 代码或商标。

## A. 构建输入

只带与当前回复有关的信息：

- 已确认的用户／对象映射；
- 最近最多 10 条原始消息，保留称呼、语气词、标点和表情；
- 当前关系与本轮目标；
- 命中的联系人事实、承诺、偏好与较早历史；
- 用户提供的 5–10 条自然口吻样本；
- 明确禁用词、长度偏好和边界。

原话优先于摘要。背景事实不得与当前对象串用。没有资料时保持未知，不用“像真人”四个字替代风格证据。

## B. 起草前诊断

在内部判断以下项目，并将结果用于选定唯一主动作：

1. 最新消息是字面信息，还是包含试探、抱怨、暗示、调侃或边界？
2. 对方当前更需要：承接、关心、解释、道歉、行动、轻松互动、空间，还是无需继续？
3. 冲突风险：低／中／高；紧张是否已经解除？
4. 是否适合提供实质内容？事实不清时优先查证或澄清，不假装记得。
5. 对方反馈：绿灯、黄灯或红灯。
6. 本轮唯一主动作：承接、降压、调侃、轻推、邀约、澄清、道歉、解释、给安排、查证、收线。

不得用“对方真实意图”把推测冒充事实。需要展示时写成“基于现有信息，更像……”。

## C. 生成候选

先在内部生成三条“动作或力度不同”的候选：

- **稳健**：准确承接，关系风险最低。
- **轻松／会撩**：增加一点具体画面、幽默或张力，必须有对方可接的出口。
- **直接／有边界**：给具体安排、表达真实意图或明确停止条件。

三条不是同义改写。若当前只有一种合理动作，生成该动作的三个措辞变体供内部筛选，但最终只展示一条。

每条遵守：

- 默认不超过 40 个汉字；冲突修复确需更多信息时可放宽，但仍优先删减。
- 一条消息只承担一个主要动作，最多带一个很轻的辅助动作。
- 对方一句话，默认不回一篇小作文。
- 沿用用户样本中的句长、称呼、语气词、标点、表情密度和熟悉度。
- 必须锚定对方刚说的具体内容；避免可群发给任何人的万能话术。
- 允许加入用户自己的观察、偏好或生活，使交流双向；不要连续审问。
- 不编造事实、记忆、承诺、共同经历或对方内心。
- 邀约尽量包含明确时间、地点或活动中的至少两个，并允许体面拒绝。

## D. 独立去 AI 排序

起草完成后，像没有参与生成一样重新审阅。每项按 0–2 判断，优先总分最高者；存在硬伤直接淘汰，不用分数掩盖。

| 维度 | 2 分标准 |
| --- | --- |
| 口吻匹配 | 像用户本人会说，长度、词汇、标点和亲密度一致 |
| 原文锚定 | 明确接住最新消息的具体细节 |
| 单一动作 | 一眼能看出本轮只在完成一件事 |
| 简洁自然 | 没有解释欲、总结欲和过度完整感 |
| 可接性 | 对方容易回应，也能体面拒绝或结束 |
| 事实纪律 | 不读心、不编记忆、不虚假承诺 |
| 关系校准 | 推进力度符合绿／黄／红灯和现实投入 |
| 自尊互惠 | 不敷衍、不乞求、不控制，也不无边界供给 |

硬淘汰项：答非所问；假装记得；未确认事实就泛泛认罪；空口保证；明确拒绝后继续推进；用操控换回应；把多个动作塞成高情商作文。

## E. AI 味清理

除非确实是用户原有口吻，删除或改写：

- “我理解你的感受”“谢谢你的坦诚”“无论如何我都希望……”；
- 先完整复述对方，再总结、分析、升华；
- 工整排比、书面连接词、客服式礼貌和咨询师口吻；
- 面面俱到、滴水不漏、替双方把所有台阶都铺完；
- 油腻称呼、套路推拉、刻意“高段位”；
- “以后会注意”“我一定改”之类没有具体行动的承诺。

不要机械禁词：如果这些表达确实出现在用户自然样本中，可保留其真实版本。

## F. 输出

用户只问怎么回时，第一屏使用：

```text
首选：
“可直接发送的话”

时机：现在／晚点／先不发
代价：最主要的一项取舍
后续：积极怎么接；含糊或不回应怎么收；拒绝时怎么停
```

仅当三种策略代表真实选择时，再展示稳健、轻松／会撩、直接／有边界三版。不要展示内部评分表或冗长诊断，除非用户要求复盘。

## G. 连续校准

把对方后续反馈当成新证据，不用结果倒推自己早已“看穿”。绿灯只加温一小步；黄灯降张力或结束当轮；红灯停止。用户明确认可某条“像我”时，只把稳定风格特征作为候选更新；单次特殊表达不永久改变档案。
